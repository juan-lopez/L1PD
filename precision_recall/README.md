# Precision & Recall
## Overview
Precision and Recall is the data validation component of L1PD. calculates the Precision, Recall and F1 score of the probes generated by comparing the LINE-1s it finds with the LINE-1s in [L1Base2](http://l1base.charite.de/l1base.php) or the alus it finds with the alus in [dbRIP](dbrip.brocku.ca/dbRIPdownload/).

## Modes
> Users can specify what mode they wish to use by using the -q parameter.
### LINE 1 Mode
If you wish to validate LINE 1 probes you must provide a reference genome, its corresponding metadata and the probes generated by the probe generator script. If you do not have a reference genome you can use [L1Base2](http://l1base.charite.de/l1base.php).

## Usage

Precision and recall can be launched launched by executing the helper shell script, `precision_recall_ss_cpp.sh`, or by compiling and running the executable manualy with the following commands.

### Compilation command
> g++ -std=c++17  -fopenmp -O2 precision_recall.cpp -o precision_recall_ex

### LINE-1 mode (without graphs)
<pre><code>./precision_recall_ex -g <i>genome.fa</i> [-e <i>edit_distance</i>] -f <i>k_probe.fasta</i> -s <i>k_samfile.sam</i> -c <i>meta_data_dir/</i> -p <i>output_dir/</i> [-t <i> start,stop,step </i>][-l <i> metadata_word_count </i>] -q <i> Line1 </i></code></pre>

### LINE-1 mode (with graphs)
<pre><code>./precision_recall_ex -g <i>genome.fa</i> [-e <i>edit_distance</i>] -f <i>k_probe.fasta</i> -s <i>k_samfile.sam</i> -c <i>meta_data_dir/ </i>-p <i>output_dir/</i> [-t <i> start,stop,step </i>][-l <i> metadata_word_count </i>] -q <i> Line1 </i> -x <i> x_axis_header </i> -y <i> y_axis_header </i> [-z <i> z_axis_header </i>] -G [-d] [--stackable]</code></pre>

### Alu mode (without graphs)
<pre><code>./precision_recall_ex -g <i>genome.fa</i> [-e <i>edit_distance</i>] -f <i>k_probe.fasta</i> -s <i>k_samfile.sam</i> -c <i>meta_data_dir/ </i>[-p <i>output_dir/</i>] [-t <i> start,stop,step </i>][-l <i> metadata_word_count </i>] -q <i> alu </i></code></pre> 

### Alu mode (with graphs)
<pre><code>./precision_recall_ex -g <i>genome.fa</i> [-e <i>edit_distance</i>] -f <i>k_probe.fasta</i> -s <i>k_samfile.sam</i> -c <i>meta_data_dir/ </i>[-p <i>output_dir/</i>] [-t <i> start,stop,step </i>][-l <i> metadata_word_count </i>] -q <i> alu </i> -x <i> x_axis_header </i> -y <i> y_axis_header </i> [-z <i> z_axis_header </i>] -G [-d] [--stackable] </code></pre>


### Mode options
<dl>
   <dt>-g --genome</dt><dd>Subject genome.</dd>

   <dt>-s --sam</dt><dd>Directory where sam files will be generated </dd>

   <dt>-c --meta</dt><dd>Metadata directory</dd>

   <dt>-f --fasta</dt><dd>Fasta file containing all the probes.</dd>

   <dt>-e --edit</dt><dd>Start, stop and step rate for varying the edit distance within mrfast</dd>
    <!-- -l will be deprecated in future implementations -->
   <dt>-l --entries</dt><dd>Amount of entries of interest for the entire genome</dd>

   <dt>-p --print</dt><dd> Directory where results and raw files will be stored. </dd>

   <dt>-t --treshold</dt><dd> Start, stop, step to vary the threshold within Precision and Recall.</dd>

   <dt>-m --MinKmers</dt><dd>Minimum amount of k mers to be used at one time. </dd>

   <dt>-G --graph</dt><dd>Argument to generate a graph from the results of Precision and recall. </dd>

   <dt>-x --x_axis</dt><dd>Header name for the x axis (this must macth the header name of the column from the results) </dd>

   <dt>-y --y_axis</dt><dd>Header name for the y axis (this must macth the header name of the column from the results) </dd>

   <dt>-z --z_axis</dt><dd>Header name for the z axis (this must macth the header name of the column from the results) </dd>

   <dt>-d --three_d</dt> <dd>Graph will be three dimensional.</dd>

   <dt>--stackable</dt> <dd>Graph will be displayed on the same plain.</dd>

   <dt>-o --output</dt> <dd>Name of the output graph. </dd>

   <dt>-q --sequence</dt> <dd>Sequence type to be evaluated </dd>


   <dt>-h --help</dt><dd>Help (shows usage).</dd>
</dl>
